# E-Commerce Global Price Guardian Bot v2.5

Developed by J. Haseeb (@haseebcomputes) as part of the 1-year Cloud Data Automation framework.

## Project Overview
An enterprise-grade Python data processing pipeline designed to monitor global e-commerce retail assets, validate data integrity, and simulate automated threshold alerts when critical price drops occur on incoming server streams.

## Core Features Deployed (Phase 1 & 2 Architecture)
- Multi-Dimensional Schema Mapping: Utilizes deeply nested data structures to handle product metadata cleanly.
- Strict Input Type Verification Guards: Implements robust type checking using isinstance() to filter out corrupted data formats.
- Anti-Injection Cyber Shield: Implicitly flags and blocks unmasked boolean overrides (True/False) from corrupting mathematical operations.
- Financial Markdown Percentage Engine: Computes real-time analytical discount rates and tracks dynamic performance vectors.

## Current Scope and Scheduled Milestones
- Current Standing: Phase 1 Core Validation and Simulation Engine is 100% verified and operational.
- Phase 3 (Scheduled): Replacing manual mock streams with dynamic live web scraping via BeautifulSoup.
- Phase 4 (Scheduled): Integrating live Google Cloud Platform (GCP) configurations and active SMTP automated email alerts.
